## Desayunado - Gameja

![$(Game Title)](Assets/Resources/Sprites/PortadaHuevada.png "$(Game Title)")

### Description

Eres un huevo que siempre soñó con ser cocinado en un desayuno. Sin embargo, todo cambió cuando tu amigo fue elegido para cumplir el papel. Fue entonces que se dió cuenta de la cruda verdad, solo eran un sacrificio. Por lo que decidió escapar en nombre de su amigo para cambiar su destino. 

### Features

 - Aparición aleatoria de enemigos con una dirección establecida.
 - Mapas con mecánicas diferentes.
 - Arte propio.

### Controls

Keyboard:
  - WASD  - player movement
